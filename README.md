# AudioVisualizer

AudioVisualizer is a real-time audio visualization application written in modern C++. The project uses OpenGL for rendering, performs FFT-based audio analysis, and is being developed as a modular graphics application with reusable rendering and UI components.

## Overview

The project captures live audio, performs frequency analysis using Fast Fourier Transform (FFT), and renders the results with a modern OpenGL pipeline. Development has expanded beyond a basic visualizer to include reusable graphics abstractions, texture support, and a foundation for interactive UI elements.

## Building

> **Note:** Currently Windows-only due to WIN32-specific code (cross-platform support planned).

### Prerequisites

1. **C++20 Compliant Compiler** (MSVC / Visual Studio 2022, GCC 10+, or Clang 12+)
2. **CMake** (v3.20 or higher)
3. **Conan 2.x** (`pip install conan`)

## Step 1: Detect Conan Profile (First-time setup only)

If you are using Conan for the first time, generate a default profile:

conan profile detect --force

## Step 2: Install Dependencies

Run Conan from the project root directory to download, build, and configure required libraries into the local `build` directory:

conan install . --output-folder=build --build=missing -s build_type=Debug

## Step 3: Configure, Build, and Run

### Option A: Command Line

1. Configure CMake using the preset generated by Conan:
   cmake --preset conan-default

2. Build the project executable:
   cmake --build --preset conan-debug

3. Run the application:
    - Windows:     .\build\Debug\AudioVisualizer.exe

### Option B: IDE Integration (CLion, Visual Studio 2022, VS Code)

1. Execute Step 2 (`conan install ...`) once in your project root terminal.
2. Open the project root folder in your IDE.
3. The IDE will automatically read `CMakeUserPresets.json` generated by Conan.
4. Select `conan-default` from your IDE's CMake presets dropdown and run/debug.
